- **YouTube and Kick VODs** now work in the Clip tab, not just Twitch.
- **Faster clips:** the sound downloads first and Whisper starts on it while the video is still downloading. Text translation is about 6x faster, and spotting champions on screen about 4x faster.
- **Re-running a section reuses its downloads**, so trying another model or setting starts straight away.
- **Subtitles line up exactly with the video.** Twitch video downloads can start a second or more off; the app now measures that and moves the subtitles to match.
- **Slang list:** gamer slang the translator would take literally ("jugadón", "de menos a más", "tilteado", "amassou") is explained in plain English before translating. Add your own in the Glossary tab.
- **Label speakers** (Clip tab option): when several people talk, other voices get coloured subtitles.
- **Report a problem** in Settings opens a GitHub issue with the details filled in. If the app ever closes unexpectedly, it offers this at the next start.
- **Go back to the old version** from this window or from Settings if something's wrong with an update.
- Fixed a crash when reading champions from the video at the same time as transcribing.
